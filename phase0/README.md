# Phase 0: Discovery And Clinical Safety

Start date: 2026-07-03
Planned duration: 4-8 weeks

Phase 0 is the research-and-safety foundation for the digital recovery platform. The goal is not to build the product yet. The goal is to learn what is safe, useful, technically realistic, ethically acceptable, and emotionally trustworthy before writing production architecture or code.

## Operating Principle

Do not build invasive monitoring until we understand user safety, consent, clinical boundaries, abuse risk, and what actually helps during real high-risk moments.

## Primary Goals

1. Understand relapse sequences across different user profiles, device setups, belief systems, relationship contexts, and severity levels.
2. Interview therapists, coaches, and recovery supporters to understand what software should and should not do.
3. Define safe language: non-shaming, non-diagnostic, serious without being punitive.
4. Define consent boundaries for adult self-use, partner/family support, ally alerts, and future strict modes.
5. Prototype the first non-code artifacts: Device Constitution, relapse debrief, ally signal copy, and safety escalation paths.
6. Identify Phase 1 MVP constraints and red lines.

## Non-Goals

- No production app.
- No content classifier.
- No screenshot monitoring.
- No medical claims.
- No diagnosis of addiction or compulsive sexual behaviour disorder.
- No partner, employer, parent, or religious-group surveillance model.
- No feature that cannot be explained clearly to a user before consent.

## Suggested Timeline

### Week 1: Setup

- Finalize research protocol and consent language.
- Prepare recruitment screener.
- Identify 10-15 candidate user participants.
- Identify 5-8 therapist, coach, or group-facilitator participants.
- Create a secure research-data folder and naming convention before collecting notes.

### Weeks 2-3: User Discovery

- Run 8-12 user interviews.
- Capture relapse sequences without collecting explicit sexual content.
- Map device setups and bypass patterns.
- Test Device Constitution and relapse debrief language.

### Weeks 3-4: Expert Discovery

- Run 5-8 therapist/coach interviews.
- Review safety language, escalation thresholds, and harm risks.
- Ask where software should defer to humans.

### Weeks 4-5: Supporter Discovery

- Run 5-8 interviews with allies, partners, or accountability supporters.
- Validate minimal-disclosure signaling.
- Identify coercion and privacy failure modes.

### Weeks 5-6: Synthesis

- Create relapse sequence archetypes.
- Identify top intervention moments.
- Rank product risks.
- Decide which Phase 1 features are safe enough to prototype.

### Weeks 7-8: Phase 1 Readiness

- Update product brief with evidence.
- Produce Phase 1 MVP scope.
- Decide what must be clinically reviewed before implementation.
- Decide whether any feature risks medical-device or regulated digital-health treatment claims.

## Phase 0 Success Criteria

Phase 0 is complete only when we can answer:

- Who is the first safe target user?
- What language reduces shame without minimizing seriousness?
- What data is absolutely necessary for Phase 1?
- What should never be shared with allies by default?
- What are the most common relapse sequences?
- Which interventions feel supportive rather than controlling?
- Which platform controls are realistic for the MVP?
- What claims must we avoid until clinical validation exists?
- What is the safest first version of the Device Constitution?
