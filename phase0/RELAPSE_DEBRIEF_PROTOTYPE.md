# Relapse Debrief Prototype

This is a non-shaming debrief after a lapse. It should be short, calm, and repair-oriented. The goal is learning, not punishment.

## Opening Copy

You do not need to punish yourself to learn from this. Let us find the first point where the system can support you better next time.

## Quick Debrief

1. When did the sequence start?
2. What was happening before it started?
3. Which feeling was strongest?
4. Which device was involved?
5. What was the first small step in the chain?
6. Did you try to bypass a protection?
7. What would have helped 10 minutes earlier?
8. Is there one rule you want to adjust while calm?
9. Is there one repair action for the next 24 hours?
10. Do you want help from someone, or privacy right now?

## Repair Action Menu

- Sleep reset.
- Message a trusted person.
- Go outside for 5 minutes.
- Clean the physical space.
- Move phone charger out of bedroom.
- Write one trigger note.
- Schedule a therapy/coaching note.
- Re-enable a protection.
- Do nothing except stop the spiral and start tomorrow cleanly.

## What The App Should Not Say

- "You failed."
- "Your streak is ruined."
- "You are back to zero."
- "Your ally has been told everything."
- "You are weak."

## Product Learning Output

After the debrief, the product should produce only one suggested adjustment:

- Add an earlier intervention point.
- Add a time-based friction rule.
- Add a device rule.
- Add a replacement action.
- Add an ally option.
- Add a sleep or travel rule.
- No change; user needs rest first.
