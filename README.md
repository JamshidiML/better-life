# P-Vermeiden

P-Vermeiden is an early-stage product research and startup project for a consent-based digital recovery platform. The goal is to help adults reduce unwanted compulsive pornography use and related digital sexual behavior through privacy-preserving recovery tools, device friction, human support, and long-term autonomy.

This repository is currently in Phase 0: Discovery And Clinical Safety. We are intentionally not building invasive monitoring yet.

## Phase 0 Principle

Do not build the product before understanding safety, consent, privacy, user needs, clinical boundaries, and platform limitations.

## Near-Term Work

1. Create the GitHub repository and push this foundation.
2. Run Phase 0 interviews with users, therapists/coaches, and allies.
3. Synthesize the first evidence batch.
4. Decide the safest Phase 1 MVP scope.
5. Build only the features that pass the Phase 0 safety gates.

## Safety Position

This product is not a therapist, medical device, emergency service, or diagnostic tool. It should support voluntary behavior change while minimizing shame, coercion, and sensitive-data collection.
