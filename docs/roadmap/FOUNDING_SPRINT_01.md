## Workstream F — Product Shape Exploration

Owner: ChatGPT with founder input

Evaluate at least four coherent product forms:

### Option 1 — Web Command Center First

Web setup and reflection experience; uses existing device controls and guided setup before custom enforcement components.

### Option 2 — Mobile App First

Native app focused on calm-state plan, high-risk intervention, and platform-specific protection capabilities.

### Option 3 — Browser Extension First

Fastest direct intervention inside web browsing, paired with a lightweight account and mobile companion.

### Option 4 — Layered Suite

Shared account and command center plus separate mobile, browser, desktop, and network components.

Evaluate each on:

- user value;
- setup simplicity;
- technical strength;
- bypass resistance;
- privacy;
- app-store feasibility;
- development cost;
- maintenance burden;
- cross-platform consistency;
- speed to first useful release.

Decision required:

- Choose a first product wedge, not the entire final platform.

## Sprint Guardrails

- Do not build an invasive monitoring product.
- Do not select a platform based only on founder preference.
- Do not claim clinical effectiveness.
- Do not collect real participant data until storage, consent, and de-identification procedures are defined.
- Do not make “impossible to bypass” promises.
- Do not confuse a sophisticated concept document with user validation.
